# 记单收款 V1 · 升级清单

适用：自己一个人记单、收钱、盯进度。代码在 `feat/solo-v1` 分支（backend、admin 两个仓库；客户端 app 没有改动）。

> **从旧版一次升到最新**：直接按 [上线手册.md](上线手册.md) 做，它已经包含这份清单的数据库步骤。
> **线上已经是补丁包版本（`feat/hardening-v1`）**：只需要照这份清单做。

## 这一版改了什么

1. **收款流水账**：每收一笔记一条（金额、日期、备注，如定金/尾款）。订单的“已收金额”是流水合计，“已收清”由系统自动判断（已收 ≥ 报价且大于 0）。可以多次收、记错了能删，都会进操作日志。
2. **接单管理**：看板卡片和列表新增“欠多少 / 已收清”；列表每行有「收款」按钮；收款筛选改成「还欠款 / 部分已收 / 已收清」。
3. **数据站**：新增“本月实收、累计实收、待收款”，近 6 个月实收柱图；已经完成但没收齐款的项目会单独提醒；只有一个人时不再显示“成员工作量”图和“待验收”卡。
4. **一键完成**：列表每行「完成」；总管理员自己负责的项目，工作台上“开始做”之后直接“完成”，不再要自己给自己“提交验收→验收通过”。
5. **极速建单**加了“客户”一栏，输入时可以选以前填过的客户，联系方式自动带出；**建单失败不会再假装成功**（失败时窗口和已粘贴的内容都留着）。
6. **搜索**现在能搜联系方式和需求内容。
7. **Excel 导出**：“收款”一列换成 已收 / 未收 / 收款情况 三列。
8. **修了几处“假成功”**：看板拖动、工作台一键操作，服务器没改成功时不再弹“成功”，并把卡片放回原位。
9. **状态值校验**：后端拒绝不认识的状态（以前传什么存什么）。
10. **一步派单**（老板）：卡片、列表、工作台上点负责人的名字或“派给”，直接选人，菜单里写着每个人手上有几单，对方立刻收到通知，不用再打开编辑窗口。
11. **一键筛选条**（接单管理）：顶上一排按钮 全部 / 待确认 / 进行中 / 待验收 / 已逾期 / 还欠款 / 已完成，每个带数量；老板还有一排“看谁的”（所有人 / 我自己 / 每个员工）。原来的状态、收款、负责人下拉和“仅看逾期”都换成了这排按钮。会记住上次用的是看板还是列表。
12. **完成时顺手问收款**：把项目改成“已完成”（验收通过、列表“完成”、拖到已完成列、详情里改状态）且还有欠款时，弹窗问“这单收到钱了吗”：已收清（一键记尾款/全款）/ 收了一部分… / 还没收先挂着。
13. **员工精简**：员工的左侧菜单不再有“数据站”；员工看不到派单菜单和“看谁的”那一排。
14. **“还欠款”不含已取消的项目**（取消了就不再追款），数据站“待收款”同口径。

## 升级步骤

线上已是补丁包版本时：

```bash
# 1. 备份（必须）
mysqldump --defaults-extra-file=/opt/xuancheng-order/config/mysql-root.cnf \
  --single-transaction xc_jiedan \
  > /opt/xuancheng-order/backups/xc_jiedan_before_solo_v1_$(date +%F_%H%M).sql

# 2. 升级数据库（只新增字段和表，可重复执行，旧版后端不受影响）
M="mysql --defaults-extra-file=/opt/xuancheng-order/config/mysql-root.cnf --default-character-set=utf8mb4"
$M xc_jiedan < upgrade_solo_v1.sql
$M xc_jiedan -e "show tables like 'jiedan_payment'; show columns from jiedan_order like 'received_amount'; select count(*) as 补录的流水数 from jiedan_payment"
```

3. 放入新版本目录、切换 `current`、重启后端——和上线手册第六步完全一样。
4. 浏览器 Ctrl+F5 强刷一次后台页面。

## 验收

- [ ] 「接单管理」里选一个有报价的项目 → 点「收款」→ 记 1000 → 窗口关闭，看板/列表上变成“欠 报价-1000”。
- [ ] 再点「收款」→ 点“收清 ¥…” → 记一笔 → 变成“已收清”。
- [ ] 点历史记录的「删除」→ 欠款回来。
- [ ] 「数据站」本月实收 = 这个月记的收款合计；近 6 个月柱图对得上。
- [ ] 记一笔比报价还多的收款，会先弹确认；记金额 0 或日期是将来的，会被拒绝。
- [ ] 员工记收款要先提交申请，老板确认后才入账（见《流转审批升级清单》）；数据站只统计自己名下项目的；客户端（客户登录）看不到任何收款信息。
- [ ] 列表里点一个进行中项目的「完成」→ 状态变已完成。
- [ ] 极速建单：填客户名（能选到以前的客户）→ 建单 → 看板卡片上显示客户名。
- [ ] 导出 Excel：有“报价、已收、未收、收款情况”几列。
- [ ] **派单**：老板在看板卡片上点负责人的名字 → 选一个员工 → 提示“已派给 XX”，该员工登录后能在自己的列表里看到这单。
- [ ] **筛选条**：点“已逾期”“还欠款”，列表只剩对应的项目；点员工的名字，只看 TA 的。
- [ ] **完成问收款**：列表里点一个有欠款项目的“完成” → 弹出“收到钱了吗” → 点“已收清” → 该项目变成“已收清”，数据站本月实收增加。
- [ ] 员工登录：左侧没有“数据站”，看不到派单入口。
- [ ] 操作日志里能看到“记收款 / 删除收款”。

## 回滚

- **只做了数据库**：不用回滚，新字段和新表旧版后端用不到。
- **已经切换版本，要退回补丁包版本**：把 `current` 切回旧版本目录并重启后端即可。新记的收款流水留在数据库里，旧版看不到也用不到；以后再升上来它们会自动回来。旧版后台没有收款入口，所以退回后“已收款”相关的显示会消失，但数据不会丢。

## 已知限制

- 收款：老板可以直接记；员工只能提交收款申请，老板确认后才入账（流转与审批版本起）。
- 收款日期不能是将来的日期（允许比今天晚 1 天，兼容时区）；可以比报价多收（会弹确认）。
- 已取消的项目收过的钱仍计入实收（钱是真收到了），但不计入“待收款”。
- 数据站的“实收”按收款日期统计，不是按项目完成日期。
- 收款流水不能改，只能删了重记（改动会留在操作日志里）。
